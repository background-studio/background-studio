# Background Studio v0.3.7

## 更新检查与插件目录

- 官方插件目录、插件版本与壳版本改为读取组织维护的静态 JSON 清单，不再逐仓库调用 GitHub REST API；无需安装或登录 GitHub CLI。
- 通过缓存、条件请求和失败退避减少重复查询；网络异常保留上次有效数据并提示，不将失败显示成“已经是最新版”。
- 保留内置离线目录和本地自定义插件目录；清单更新可发现新增官方插件，不需要每加一个插件就重装壳。
- 官方下载记录提供 SHA-256 时，安装前验证文件摘要；仍需用户点击安装或更新，不做静默升级。
- 新增更新诊断入口，使用同一查更逻辑，仅写入查更/图标缓存及诊断报告，不启动插件、不修改插件配置、背景档案或开机启动。

## 插件与安全修复

- 内置 Factory 插件目录项和专用组合图标，配套插件 v0.1.1。
- 保留轮播安全修复：协议 2 轮播仅下发 configure 热更新，不再额外 apply 导致失效会话触发目标程序重启。
- 安装包同时提供 SHA-256 校验文件。

## 注意

- 官方清单由组织工作流定期更新，Release 发布至清单可见存在同步延迟；GitHub 静态站点或下载站点仍需网络可达。
- 第三方自定义仓库不在官方清单中，仍使用原有 GitHub 查询方式，可能受其限流影响。
- Factory 的间歇性账号接口网络错误尚未定位，本次版本不宣称修复；其完整浅色主题切换、视频及终端专用视图的运行时验证限制不变。
