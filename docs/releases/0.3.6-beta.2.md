# Background Studio 0.3.6-beta.2

本版延续预发布渠道，配套 **Cursor Agent Background Studio 0.1.4-beta.1**。稳定版仍保留为 0.3.5。

## 新增

- 内置 Cursor Agent 插件目录项与图标。
- 对运行时声明 `perWindowMedia` 能力的插件，按窗口分别选图、计时和下发配置；旧插件继续使用原协议。
- 支持文件夹和播放列表，随机/顺序选择优先避开其他窗口占用的文件和自己的上一张；图库不足时允许重复。
- 新窗口不改变已有窗口的图片和计时点；显示设置变更复用现有选择，关闭窗口后释放媒体槽，暂停期间不自动唤醒插件。
- 每个窗口使用独立的回环下载槽，避免其他窗口或预览换图改变下载内容；继续校验媒体大小、MIME 与 SHA-256，不向插件传递本机路径。

## 升级说明

先更新宿主，再从预发布插件渠道更新 Cursor Agent 插件。独立窗口分发需要两端同时更新。

本版不要求重启已经开启合法本机调试口的 Cursor；普通未启用调试的 Cursor 仍遵守原有“用户主动应用后才接管”的规则。

## 验证范围

- 宿主 32 项、插件 22 项自动化测试通过，两端 release 构建通过。
- 真实单窗口随机轮播、Agent/IDE 背景隔离、Agent 窗口关闭后重新打开自动应用背景均通过。
- **多窗口同时运行尚未真实联调**；独立选择、计时、媒体下载隔离与新窗口不扰动旧窗口由自动化测试覆盖。
