# Background Studio v0.3.5

## 修复

- 修复插件远端版本低于本地版本时，仍显示“更新”和反向版本箭头的问题（例如 `0.3.7 → 0.3.6`）。
- 插件更新改为按语义化版本比较，仅远端版本严格高于本地时提示更新，正确处理 `v` 前缀、多位数字及预发布版本。
- 安装入口增加版本校验：在下载或停止插件之前拒绝降级、相同版本覆盖和无法比较的版本，防止旧 Release 缓存覆盖本机修复版。

## 验证

- 27 项宿主单元测试通过，包含升级、降级、同版本、预发布及非法版本回归测试。
- 保持现有插件、媒体库与用户设置不变。

建议搭配 Grok Bot Background Studio v0.3.7 使用，后者修复 Grok Bot 0.57.1 的接管兼容性。
