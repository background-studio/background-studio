# Background Studio v0.3.6

本版把 0.3.6-beta.1 与 0.3.6-beta.2 转为正式版，配套 **Cursor Agent Background Studio 0.1.4** 与 **Rebased Background Studio 0.1.2**。

## 新增

- 内置 Cursor Agent 与 Rebased 插件目录项及图标。
- 对运行时声明 `perWindowMedia` 能力的插件，按窗口分别选图、计时和下发配置；旧插件继续使用原协议。
- 支持文件夹和播放列表，随机/顺序选择优先避开其他窗口占用的文件和自己的上一张；图库不足时允许重复。
- 新窗口不改变已有窗口的图片和计时点；显示设置变更复用现有选择，关闭窗口后释放媒体槽，暂停期间不自动唤醒插件。
- 每个窗口使用独立的回环下载槽，避免其他窗口或预览换图改变下载内容；继续校验媒体大小、MIME 与 SHA-256，不向插件传递本机路径。

## 性能

- 界面改用 DX12 渲染，并请求低功耗显卡，笔记本不再唤醒独显；DX12 无法初始化时回落到 OpenGL。修复 Intel 核显上悬停界面时持续重绘、空等垂直同步占满一个核心的问题（约 1022 ms CPU/s 降至 147 ms CPU/s）。

## 升级说明

先更新宿主，再更新插件。按窗口独立分发需要宿主与插件两端同时更新；未更新的插件仍按单媒体模式工作。

本版不要求重启已经开启合法本机调试口的 Cursor；普通未启用调试的 Cursor 仍遵守原有“用户主动应用后才接管”的规则。保留现有插件、媒体库与用户设置。

## 验证

- 宿主 32 项自动化测试通过。
- 真实单窗口随机轮播、Agent/IDE 背景隔离、Agent 窗口关闭后重新打开自动应用背景均通过。
- 经预发布渠道数日实际使用，未发现问题。
